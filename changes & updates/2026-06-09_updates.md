# Updates - June 9, 2026

Here is a summary of all the changes and updates made today for the M.A.D (Money Analysis and Decisions) application:

### 1. Server Restart & Fixes
- Restarted the local development backend server (`npm run dev`) that was previously stuck/not responding.
- Cleared up hung Node.js processes from the background.

### 2. Split Expense UX Improvements
- **Added Friend directly from Split Picker:** Added a new **+ Add Friend** button in the "Split with" section of the Split Expense modal.
- **Wired up Add Friend Overlay:** Clicking this new button in the split modal immediately opens the Add Friend overlay, making the user flow much more seamless.

### 3. Profile Settings Cleanup
- **Removed Duplicate Options:** Removed the "Add Friend" button from the main profile settings dropdown, making the split picker the exclusive place for adding friends as requested.
- **Cleaned Up Logic:** Removed the now-unused event listeners for the profile add friend button from `app.js`.

### 4. UI & Theming Enhancements
- **Themed Profile Menu:** Completely restyled the profile dropdown menu to match the application's sleek dark theme and color tokens.
- **Created Proper CSS Classes:** Replaced clunky inline styles (`style="..."`) in `index.html` with proper, reusable CSS classes (`.profile-menu__item`, `.profile-menu__divider`) in `index.css`.
- **Aesthetic Hover States:** Added smooth hover states for menu items.
- **Log Out Button:** Added a specific `.profile-menu__item--danger` variant for the Log Out button, giving it a beautiful and clear warning red aesthetic.

### 5. Dynamic Profile Theming
- **Dynamic Avatar Gradients:** Removed hardcoded blue-purple linear gradients (`#4f46e5`, `#0ea5e9`) across all profile avatars and replaced them with the live `var(--accent-gradient)` so they adapt to the app's Mood Engine dynamically.
- **Dynamic Toggles:** Updated the dark mode toggle switch active color from a hardcoded indigo to `var(--accent-1)` to ensure it responds to the user's live health score and matches the rest of the application.

### 6. Bug Fixes
- **Profile Picture Upload Fixed:** Increased the JSON payload size limit on the backend (`express.json({ limit: '10mb' })`) to successfully parse and process base64 image strings without throwing a `PayloadTooLargeError`, enabling seamless profile picture uploads.
